# EDA on Retail Sales Data

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer demographics, product performance, and useful business insights.

## Objective

The main objective is to analyze retail sales data and discover meaningful patterns and trends using Python.

## Dataset

The dataset contains 1,000 retail transactions and 9 columns.

Columns include:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis Performed

- Checked dataset shape, columns, and data types.
- Checked missing values and duplicate records.
- Generated descriptive statistics.
- Converted the Date column into datetime format.
- Analyzed sales by product category.
- Analyzed sales by gender.
- Analyzed customer purchase behavior.
- Identified top customers.
- Analyzed sales trends.
- Created visualizations using bar charts.
- Created a correlation heatmap to understand relationships between numerical variables.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights

- Sales performance varies across different product categories.
- Customer demographics provide useful information about purchasing behavior.
- Product category analysis helps identify better-performing products.
- Sales trends can help understand changes in business performance.
- Correlation analysis helps identify relationships between numerical variables.

## Conclusion

The EDA successfully identified important patterns and trends in the retail sales dataset. The analysis provides useful insights into product performance, customer behavior, and sales trends.
