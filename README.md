EDA on Retail Sales Data

-Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer demographics, product performance, and useful business insights.

-Objective
The main objective of this project is to analyze retail sales data and discover meaningful patterns and trends.

-Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

-Analysis Performed
- Data Cleaning and Inspection
- Descriptive Statistics
- Sales Trend Analysis
- Monthly Sales Analysis
- Customer Demographics Analysis
- Product Category Analysis
- Gender Analysis
- Correlation Heatmap

-Dataset
The dataset contains retail transaction information including:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

-Key Insights
- Sales fluctuate across different months.
- Product categories show different levels of sales performance.
- Customer demographics help understand purchasing behavior.
- Price per unit has a strong relationship with total sales amount.
- Correlation analysis helps identify relationships between numerical variables.

-Project Files
- `EDA_Retail_Sales.ipynb` – Complete EDA analysis
- `analysis.py` – Python analysis code
- `retail_sales_dataset.csv` – Dataset
